This game has gone crazy-viral this month. An indie dev called [Miziziziz](https://www.deeproot.dev/) put out a [YouTube video](https://www.youtube.com/watch?v=MPiRApONQxU) explaining the development of his latest game jam project - a goofy top-down puzzle game with a unique control scheme. 

It's a fun game with a great explaination video. Go play the demo on [itch.io](https://nartier.itch.io/walkable-cities). A full version is coming to [Steam](https://store.steampowered.com/app/5015460/Walkable_Cities/) in the future.
